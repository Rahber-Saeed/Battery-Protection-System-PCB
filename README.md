Overcharge protection

Over-discharge protection

🧠 Project Overview
Battery protection circuits are essential for maintaining the safety and lifespan of rechargeable batteries.

This project focuses on designing a PCB that:

Prevents battery damage

Ensures safe voltage limits

Protects against excessive current
